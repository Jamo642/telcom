🏗️ How the Pipeline Works
Data Sources
📊 SQLite — live alarm database (telenoc.db). Every diagnosed alarm is stored here with severity, root cause, MTTR timer.
📄 Log files — raw device logs per node. The agent calls get_logs(node) to read them in real time.
🧠 ChromaDB — vector database of 50 telecom runbooks and past incidents. Searched by semantic similarity (BAAI/bge-small embeddings).
🛡️ MITRE FiGHT — 10 curated 5G attack techniques. Matched against alarm text using keyword + phrase scoring.
Agent Tools
🔧 get_active_alerts — query live incidents by severity / node
🔧 get_logs — read raw log files for a given node
🔧 lookup_incident — fetch a specific alarm by ID
🔧 search_knowledge_base — semantic RAG over runbooks
🔧 detect_fight_techniques — run MITRE FiGHT scan
🔐 remediate_fight_technique — gated — requires confirmed=true
OPEA Integration: When started with ./deploy.sh --opea, the RAG layer switches from local ChromaDB to opea/embedding-tei + opea/retriever-redis + opea/chatqna. The fallback to local ChromaDB is automatic — zero downtime.
